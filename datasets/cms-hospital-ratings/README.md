# US Hospital Ratings (CMS)

Every Medicare-certified US hospital with its CMS overall star rating, ownership, type, emergency-services flag and quality measure counts.

- **Live browsable directory:** [https://hospitals.tekify.xyz](https://hospitals.tekify.xyz)
- **Records:** 5,419
- **Source:** CMS Provider Data Catalog — Hospital General Information (public domain)
- **Licence:** Public domain (US Government work)
- **Sample:** `sample.csv` (first 300 random rows, same columns as the full file)

## Columns

`Facility ID, Facility Name, Address, City/Town, State, ZIP Code, County/Parish, Telephone Number, Hospital Type, Hospital Ownership, Emergency Services, Hospital overall rating`

## Why this exists

The Tekify network turns public datasets into readable pages, one record per page, with the fields
that matter and links to the surrounding records. This folder publishes a sample of the same data so
you can evaluate it before using the directory, and so the dataset can be mirrored to open-data
platforms (Hugging Face, Zenodo) with the same provenance.
