# US Dialysis Facilities (CMS)

Medicare-certified dialysis facilities with the CMS five-star rating, survival/hospitalisation/readmission measures, services offered and station counts.

- **Live browsable directory:** [https://dialysis.tekify.xyz](https://dialysis.tekify.xyz)
- **Records:** 7,490
- **Source:** CMS Provider Data Catalog — Dialysis Facility Listing (public domain)
- **Licence:** Public domain (US Government work)
- **Sample:** `sample.csv` (first 300 random rows, same columns as the full file)

## Columns

`CMS Certification Number (CCN), Facility Name, City/Town, State, ZIP Code, Profit or Non-Profit, Chain Organization, # of Dialysis Stations, Offers in-center hemodialysis, Five Star`

## Why this exists

The Tekify network turns public datasets into readable pages, one record per page, with the fields
that matter and links to the surrounding records. This folder publishes a sample of the same data so
you can evaluate it before using the directory, and so the dataset can be mirrored to open-data
platforms (Hugging Face, Zenodo) with the same provenance.
