# Open datasets

Samples and dataset cards for the public datasets behind the Tekify directories. Each folder has a README with provenance and a `sample.csv`.

| Dataset | Records | Live directory |
|---|---|---|
| [Indian Bank IFSC Codes](ifsc-codes/README.md) | 183,214 | [https://ifsccodes.tekify.xyz](https://ifsccodes.tekify.xyz) |
| [US ZIP Codes](us-zip-codes/README.md) | 41,711 | [https://zipcodes.tekify.xyz](https://zipcodes.tekify.xyz) |
| [US Hospital Ratings (CMS)](cms-hospital-ratings/README.md) | 5,419 | [https://hospitals.tekify.xyz](https://hospitals.tekify.xyz) |
| [US Dialysis Facilities (CMS)](us-dialysis-facilities/README.md) | 7,490 | [https://dialysis.tekify.xyz](https://dialysis.tekify.xyz) |

The full data is served by each directory as JSON under `/data/` (for example <https://zipcodes.tekify.xyz/data/zips.json>).
