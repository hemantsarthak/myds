# US ZIP Codes

US ZIP codes with city, state, county, coordinates and population, plus links to the places and area codes that overlap them.

- **Live browsable directory:** [https://zipcodes.tekify.xyz](https://zipcodes.tekify.xyz)
- **Records:** 41,711
- **Source:** US Census Bureau / GeoNames (public domain, CC BY 4.0)
- **Licence:** Public domain / CC BY 4.0
- **Sample:** `sample.csv` (first 300 random rows, same columns as the full file)

## Columns

`zip, city, state, state_name, type, county_fips, county_name, county_fips_all, lat, lng, coord_source, is_zcta, parent_zcta, population`

## Why this exists

The Tekify network turns public datasets into readable pages, one record per page, with the fields
that matter and links to the surrounding records. This folder publishes a sample of the same data so
you can evaluate it before using the directory, and so the dataset can be mirrored to open-data
platforms (Hugging Face, Zenodo) with the same provenance.
