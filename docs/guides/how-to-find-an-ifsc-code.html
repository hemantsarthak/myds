How to find an IFSC code (and what each part means)

What an IFSC code is, how the eleven characters break down, and how to look up any Indian bank branch's code safely before a transfer.

An IFSC (Indian Financial System Code) identifies one specific bank branch. It is eleven characters: four letters for the bank, a zero, and six characters for the branch. NEFT, RTGS and IMPS transfers all need it, and it is printed on cheque books and account statements.

Reading the code

Take HDFC0000001: HDFC is the bank, the fifth character is always 0, and 000001 identifies the branch. Because the bank part is repeated across every branch, a code that starts with the right letters can still point at the wrong branch.

Look it up before you transfer

Check the code against the branch record — bank, branch name, address, district and MICR code — rather than trusting a code copied from a message. The free directory at IFSC Codes India lists 19,511 branches with those fields, searchable by code, bank, city or district.

Common mistakes

  • Confusing the MICR code with the IFSC code. MICR is a nine-digit cheque-clearing code; IFSC is eleven characters and used for electronic transfers.
  • Using a closed branch's code. Merged banks keep old codes active for a while but transfers may be redirected; check the branch is still open.
  • Typing the code by hand. Copy it, then verify the branch name on the record.
