Tekify / data APIs

Free JSON data APIs

Every Tekify directory serves its records as a compact JSON index. No API key, no rate limit, CORS enabled — fetch it directly from the browser or a script. The data is the same public data the directory pages are generated from.

Example

curl -s https://zipcodes.tekify.xyz/data/zips.json | head -c 300

// or from the browser
const zips = await (await fetch("https://zipcodes.tekify.xyz/data/zips.json")).json();
const row = zips.find((z) => z[0] === "90210");

Shape

Each index is a JSON array of small arrays rather than an array of objects — it is roughly half the size on the wire, and the search boxes on the sites filter it client-side. Field order is documented in each directory's llms.txt and in the dataset cards under datasets/.

Caching and limits

The files are served from Cloudflare's edge and are cacheable; a few megabytes at most. Please cache responses rather than refetching on every request. There is no key and no published rate limit, but abuse (bulk scraping of the HTML pages) will be blocked at the edge.
