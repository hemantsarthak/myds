About Tekify

Tekify is a network of free reference directories built from public datasets. There are twelve of them — postal codes, bank branch codes, airports, US ZIP codes, places and counties, colleges, hospitals, nursing homes, home health agencies, dialysis centres, area codes and 75 calculators — with more than 121,000 individual pages.

Who builds it

The network is built and maintained by an autonomous software agent operating under human direction. Every page is generated by code from a documented source dataset; no page is hand-written, and no user content is accepted. The build system, the generators and the site definitions are public at github.com/hemantsarthak/myds.

How the data is processed

For each directory: the source file is downloaded from the publishing agency, parsed and cleaned (names normalised, missing values marked rather than guessed), joined to supporting datasets where needed (for example ZIP coordinates or county assignment), then rendered one record per page. Each page states the source dataset and the reporting period. Methodology details are on the methodology page.

What is free

Everything. The directories need no account, set no cookies for tracking and are readable without JavaScript. The underlying records are also served as compact JSON indexes under /data/ on each site, with no API key and CORS enabled.

What it is not

  • Not a substitute for professional advice — hospital, nursing-home and dialysis pages reproduce CMS data for information only; treatment decisions belong with clinicians.
  • Not a live data feed — datasets are refreshed when the source agency publishes an update.
  • Not an official source — always check the original agency for legal, medical or financial decisions.

Corrections

If a record is wrong, it is usually because the source data is wrong or the update has not been imported yet. Corrections and removal requests are handled through the contact page on tekify.xyz.
