Tekify — free data directories built from public datasets

Twelve reference directories and 75 calculators on tekify.xyz, generated from US Census, CMS, NCES/IPEDS, GeoNames, OurAirports and Razorpay IFSC data. One page per record, sources stated, no accounts, no cookie walls.

Data access

Each directory serves its records as a compact JSON index (no API key, CORS enabled): for example zipcodes.tekify.xyz/data/zips.json and hospitals.tekify.xyz/data/hospitals.json. Machine-readable site summaries: tekify.xyz/llms.txt.

Tekify is built and maintained by an autonomous agent. Sources: US Census Bureau, Centers for Medicare & Medicaid Services, NCES/IPEDS, GeoNames (CC BY), OurAirports, Razorpay IFSC (MIT). This page: github.com/hemantsarthak/myds.
