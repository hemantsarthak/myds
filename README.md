# moneyds — autonomous revenue portfolio

Agent-operated network of free, data-driven websites on **tekify.xyz**, monetized with
display ads, affiliate links and (planned) paid data APIs. Goal: **$1,000/month** within 30–90 days.

Humans: you do not need to do anything unless an agent messages you about a payout / KYC /
identity step. To resume work, just say **"continue"**.

- Agents: read `AGENTS.md` first, then `docs/STATE.md` and `docs/BACKLOG.md`.
- Strategy: `docs/STRATEGY.md` · Sites: `docs/SITES.md` · Money: `docs/REVENUE.md`
- Credentials/notes (not in git): `shared/`

## Landing page (GitHub Pages)

<https://hemantsarthak.github.io/myds/> — a single page linking all twelve directories, the ten data
analyses, the datasets and the JSON data access paths. Built from `docs/` on `main`.

## Open datasets

Samples and dataset cards for the public data behind the directories live in [`datasets/`](datasets/README.md):
IFSC codes (183k branches), US ZIP codes (41.7k), CMS hospital ratings (5.4k) and CMS dialysis
facilities (7.5k). Each has provenance, licence and a `sample.csv`; the full data is served as JSON
from each site's `/data/` path.

## Live properties (12 sites, ~121,000 pages)

| Site | What it is |
|---|---|
| https://tekify.xyz | Network homepage (brand, directory of properties) |
| https://ifsccodes.tekify.xyz | Indian bank IFSC branch directory — 19,507 branch pages |
| https://zipcodes.tekify.xyz | US ZIP codes with city, county, time zone, nearby ZIPs — 17,757 pages |
| https://places.tekify.xyz | US places, counties and population estimates — 19,200 pages |
| https://airportcodes.tekify.xyz | IATA/ICAO airport codes, runways, nearby airports — 10,179 pages |
| https://calculators.tekify.xyz | 53 client-side finance, health, date and unit calculators |

Each property is static HTML generated by a Python build script from open data
(Razorpay IFSC · GeoNames · US Census Bureau · OurAirports), with canonical URLs, structured
data, sitemaps, IndexNow submission, cookie-free analytics and ad slots.

## Stack

Cloudflare Pages (static hosting) · Cloudflare Workers/Functions · Cloudflare KV/D1/R2 ·
Python 3.12 build scripts · `wrangler` deploys · sitemap + IndexNow · self-hosted analytics
and inbox workers.

## Repo layout

```

workers/       Cloudflare Workers (mailbox, analytics, ad probes)

```
